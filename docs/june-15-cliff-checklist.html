6月15日の Claude Code 課金分離の前の16日間の確認の手引き

追記（2026年6月22日）: この課金分離は施行の当日に一時停止されました。 6月15日に予定された分離はその日に一時停止され、当面は何も変わりません（claude -p・Agent SDK・GitHub Actions は今も通常の購読の枠から課金されます）。撤回ではなく停止で再び実施され得るので、本ツールは「再来への備え」としてお使いください（出典）。
