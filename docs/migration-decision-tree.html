Migration Decision Tree

Six questions, six paths. Based on the Claude Code Migration Playbook Edition 2's eight-gate decision tree. Identifies which of six paths fits your trigger count, daily spend, subscription tier, and posture preference.

The six paths in one line each: A — Stay and Fortify (keep Claude Code, add hook discipline). B — Switch Platforms (Cursor, Cline, Codex, Aider). B' — Replace the model, keep the harness (Claude Code IDE + Z.AI GLM or equivalent). C posture A — Stack-of-tools (terminal + routing CLI + sandbox + cloud env). C posture B — Backend-swap proxy (claude-code-router, deepclaude). C posture C — Hybrid delegation (Claude Code as primary, cheaper model for bulk tasks). The tree is structural — the answer depends on your trigger count, daily spend, and what you're willing to retrain on.
