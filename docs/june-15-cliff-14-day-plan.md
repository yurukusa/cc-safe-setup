# 6月15日のAnthropicの課金分離の発火の前の14日の準備の計画

最終更新: 2026年5月31日 15:35 JST

## 経路の合図

2026年6月15日にAnthropicが Claude Code の課金を変更します。 何もしないと `claude -p` と Claude Agent SDK の月の費用が **5倍から25倍に跳ねる合図** があります。 Max 5x の利用者の独立な見積もりでは月1,000米ドル相当の追加請求の見込みが複数届いています。

本文書は、 800時間以上の Claude Code の自律運用の中で、 月150-250米ドルのトークン費用と1万円程度の累計の収益で赤字の経路を歩いている非エンジニア (yurukusa) が、 6月15日の発火の前の14日 (6/1-6/14) の日別の準備の計画を articulate する経路です。

## 14日の計画の整理

### 6月1日 (日): 現状の費用の baseline の取得

| 経路 | 手順 |
|---|---|
| Anthropic Console の `Usage` の取得 | 直近30日の費用の累計と、 Pool 1 と Pool 2 の比率の合図の取得 |
| `claude -p` の使用の合図の取得 | 直近1週間の `claude -p` の使用回数と、 各々の token 消費の合図 |
| Agent SDK の使用の合図の取得 | 直近1週間の Agent SDK の使用回数と、 各々の token 消費の合図 |
| 出力先 | `~/ops/measurements/2026-06-01-cliff-baseline.json` |

baseline の取得の経路は、 6月15日の発火の後の差分の取得の経路の入力。 取得しない場合、 「同じ運用の費用が何倍に膨らんだか」 の合図が取れない。

### 6月2日 (月): 4つの対応の経路の判定の入力の整理

cliff-survival 本の4つの対応の経路の articulate を、 自分の運用の合図に適用する。

1. **対話への畳み込み**: `claude -p` の使用を対話の経路に移す経路。 Pool 1 の費用の経路で、 5倍から25倍の費用の上昇の影響が限定的。
2. **`claude -p` の最適化**: `claude -p` の使用を維持しつつ、 token 消費の最適化の経路。 CLAUDE.md の articulate の短縮、 hook の停止、 並列の道具の呼び出しの制限。
3. **API への移行**: `claude -p` を直接の Anthropic API に置換する経路。 月の費用の経路は直接の API の price で、 Pool 1 と Pool 2 の判定の対象外。
4. **2つの混在**: 重要な作業は対話、 軽い作業は `claude -p` の混在の経路。

判定の入力: 「自分の運用の中で、 どの作業を対話の経路に移し、 どの作業を `claude -p` の経路で維持するか」 の合図の整理。
