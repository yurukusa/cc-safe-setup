3. あなたにとっての意味

正直な限界 — 動く前に読んでください：
  • これは記録された entrypoint で、セッションごとに分類します。6月15日が実際に分ける単位です。cli は対話（Pool 1）。sdk-cli など cli でないものはプログラム経由（Pool 2）。
  • 画面なしの claude -p は、版によっては cli で記録されることがあります。スクリプトやcronやCIの中でClaudeを動かしていて、それが下に出ていないなら、この表示はあなたのPool 2の露出を過小に見せています。表示よりも、自分の自動化の知識を信じてください。
  • 「活動」は応答のターンの数です。正確なトークンや金額ではなく、量の代理です。少数の重いプログラムのセッションは、多数の小さいものより重要です。
  • 対話のセッションの中の子エージェントや安全装置やMCPがどちらの枠に課金されるかは予測しません。Anthropicはその分け方を定義しておらず、断定する人は推測です。この道具は、実際に定義されている部分にとどめます。
