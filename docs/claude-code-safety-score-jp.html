あなたのClaude Codeの安全設定は何点？

本書の著者は、Claude Code の環境診断スコアを 19点から85点へ上げて、800時間以上「ほぼ無人」で走らせられるようにしました。あなたの今の環境は何点でしょうか。12問・3分。データが消える・暴走する・課金が膨らむ・嘘の完了を返す——こうした取り返しのつかない事故を、設定で先回りできているかを採点します。

足りない対策を、設定で先回りする

上の「足りない対策」は、どれも実際に起きた事故から逆算したものです。各対策の hook と設定の全手順、症状から該当章へ直接飛べる早見表、19点から85点へ上げた全工程は、Claude Code 事故防止ハンドブック（¥800・第3章まで無料・全100章）にまとめています。

Kindle 版（Amazon）は Kindle Unlimited なら追加の費用なしで読めます（Kindle 版は2026年6月時点の内容で、Zenn 版の追補は入りません）。無料の防御 hook の集まりは cc-safe-setup（npx github:yurukusa/cc-safe-setup）。

事故は毎月新しい型が出ます。点数を上げたあとも、その月に報告された新しい事故と対策を月に一度まとめて追いたい人は、無料の月刊まとめ Claude Code 事故まとめ へ。さらに、検証済みの hook と安全チェックリストを添えて毎月15日ごろ受け取りたい人向けに、月額の Claude Code 安全運用便（¥500）も用意しています。

この診断は、GitHub の起票で実際に報告された Claude Code の事故と、cc-safe-setup で実装し試験を通した hook をもとに作っています。点数は、各対策の有無を重みづけで合計した目安です。リンク先の本では、それぞれの事故の機構と防ぎ方を、起票の番号つきで検証しています。
