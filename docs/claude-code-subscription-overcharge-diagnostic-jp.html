購読しているのに従量課金される — Claude Code 自己診断

6つの質問 ・ 約2分 ・ ブラウザ内で完結、登録なし、送信なし ・ CC0 ・ v1.1（2026-06-26）
「定額の購読を使っているはずなのに、従量課金が走る」「枠に余裕があるのに前払いのクレジット(Extra Usage)が減る」——2026年6月15日の課金の分離(対話的な利用と、プログラム的な利用の課金の扱いが分かれた変更)の前後で、この相談が複数の独立な経路で急増しました。Redditでは 187ドルの想定外の請求 の報告も出ています(GitHub 起票 68406)。さらに6月の末には、既定のモデルが通知なく上位へ切り替わり自動の補充が重なって 6日で506ドル という、別の機構の費用の流出も表面化しました(起票71481)。症状は似ていても、根本の原因は次の5つに分かれます。この診断で、自分がどれかを切り分けます。
Q1. 環境変数 ANTHROPIC_API_KEY が設定されていますか？
echo $ANTHROPIC_API_KEY を実行。シェルの設定ファイル(.bashrc / .zshrc)、.env、CIの環境変数、~/.claude/settings.json の env も見てください。
Q2. Anthropic 系のツールを複数入れていますか？
別の Anthropic 系の CLI や SDK、社内ツールなど、~/.config/anthropic を共有しうるものを複数入れているか。
Q3. Desktop 版と、標準の CLI を同時に使っていますか？
デスクトップのアプリと、ターミナルの claude コマンドの両方を、同じアカウントで併用しているか。
Q4. 枠に余裕があるのに、前払いのクレジット(Extra Usage)が減っていますか？
5時間や週の枠にまだ余裕がある(例: 5時間で約9%、週で約15%しか使っていない)のに、Extra Usage の前払いのクレジットが減っているか。
Q5. 1回1回のやり取りが急に高くなった、もしくはクレジットが自動で補充されていますか？
枠の減りの速さでなく、同じ作業の単価が急に上がった感覚があるか。あわせて、Anthropic の管理画面で自動の補充(auto-reload / 自動チャージ)を有効にしているか。鍵を作り直した直後やアップグレードの直後から請求が膨らんだ心当たりがあるか。
Q6. 利用の画面で「消費の出どころ」を確認しましたか？
対話的な利用とプログラム的な利用の、どちらで枠やクレジットが減っているかを、利用の画面で見たか。

この診断は、2026年6月のClaude Codeの費用の流出の事故(GitHub 起票 68406 / 68296 / 68285 / 68501 / 71481、Reddit・HN で表面化したパターン、運用のログ)から作りました。他人の起票で知った事実は伝聞として、仕組みで手元で確かめられた部分だけを断定で書いています。判定はすべてあなたのブラウザの中だけで行い、入力や結果はどこにも送信しません。CC0。
