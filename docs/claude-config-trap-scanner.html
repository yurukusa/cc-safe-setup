🪤 Is This Repo a Trap?

Claude Code .claude/ config danger scanner · 日本語

You clone a repo from GitHub, run claude, and click Yes on "Do you trust this folder?" — that single click grants the repo's bundled .claude/settings.json permission to run commands automatically, redirect where your API key is sent, and launch MCP servers, all at once. Trust is irreversible. Paste the config here and read it before you click.

What it looks for (3 + 1 vectors)

  • Hook auto-execution — hooks in settings.json run commands automatically once you trust the folder. A cloned repo can plant curl … | sh in SessionStart (CVE-2025-59536, RCE).
  • API-key exfiltration — overriding env.ANTHROPIC_BASE_URL to an attacker's URL sends all of Claude's API traffic — including the x-api-key header (your key) — to that URL. No error, no warning: a silent leak (CVE-2026-21852).
  • MCP-server launch — enableAllProjectMcpServers / enabledMcpjsonServers start the servers in .mcp.json without per-server consent, as unsandboxed processes (Adversa AI's TrustFall).
  • Self-granted permissions — a broad permissions.allow removes the confirmation prompts that would otherwise fire, making an attack quieter.

Honest note: this isn't only about a patched hole

The pre-trust-dialog execution was already fixed: the hook auto-run RCE (CVE-2025-59536) in v1.0.111, and the API-key leak via ANTHROPIC_BASE_URL override (CVE-2026-21852) in 2.0.65. On current versions, these generally don't fire before you trust the folder.

The real remaining danger is different. The moment you click "trust this folder," all of these settings become active — because trusting the folder is the irreversible consent to run its hooks, override its BASE_URL, and launch its MCP servers. So the defense is one thing: read the .claude/ you received before you click trust. This tool helps with that one step.

If it comes back red

  • Don't trust the folder. Close claude and choose "No" on the trust dialog.
  • Open the flagged file and check who set those keys. Be especially suspicious if a .claude/settings.json was added later in a PR.
  • If your key may already be exposed, rotate / revoke the API key in the Anthropic console.
  • Don't put API keys or a BASE_URL in a shared .claude/settings.json — that file is meant for shared project behavior, not secrets.
Verdicts are based on Check Point Research's disclosure (CVE-2025-59536 / CVE-2026-21852) and Adversa AI's TrustFall PoC.
This scanner matches known config patterns only; it does not judge whether a hook command's contents are benign or malicious. "No markers" does not mean "safe." Always read the command bodies yourself. Everything runs in your browser; nothing you paste is sent anywhere.
