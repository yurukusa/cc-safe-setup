SKILL.md トークン自己診断

入れているスキルの SKILL.md は、そのスキルが発火しなくても毎セッション文脈に読み込まれます。下に1つ貼ると、毎回かかる常駐トークンと、外に出せる重い塊を表示します。ブラウザの中だけで処理し、貼った内容はどこにも送信しません。

手元に無い時は、まず各スキルの大きさを一覧で：
for f in ~/.claude/skills/*/SKILL.md .claude/skills/*/SKILL.md; do [ -f "$f" ] && printf '%6s %s\n' "$(wc -c < "$f")" "$f"; done | sort -rn

トークン数は概算です（約4文字＝1トークンという英語・コード向けの粗い目安。日本語は1文字あたりのトークンが重いので、出る数字は下限と思ってください）。大事なのは正確な数字でなく、毎ターン必ず払う常駐の部分のうち、スキルが発火した時にしか要らない詳細がどれだけ混じっているか、です。貼った SKILL.md はブラウザの外に出ません。
