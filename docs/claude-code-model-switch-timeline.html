What the log proves, and what it doesn't. message.model tells you which model served a turn — it does not prove intent or that anything was "deliberately downgraded." Report the observed facts (served model and timestamp per turn) and leave the cause to whoever can audit routing. An Opus↔Opus swap (4-7 vs 4-8) is a weak signal; an Opus→non-Opus drop is the sharp one.
