毎月、何を届けるか

  • 1. 月次の事故のまとめ
    その月に Claude Code 公式リポジトリで報告された事故・退行・仕様変更を 4〜8 件、再現手順と対処方法と一緒に整理します。Issue 番号、発生のきっかけ、影響範囲、回避策をまとめます。
  • 2. 安全チェックリスト（その月の版）
    料金、秘密情報、破壊的操作、長時間セッション、公開前確認の 5 領域の月次更新版。前月との差分が分かるように書きます。
  • 3. コピペで使える hook・設定の例
    毎月 1〜2 個、その月の事故から逆算した PreToolUse / Stop hook を出します。動作確認済みのスクリプトと、適用方法を添えます。
  • 4. 失敗事例 1 件の深掘り
    その月で最も影響の大きかった事故 1 件を、症状・原因・復旧手順・予防策・月次チェック項目の追加まで分解します。同じ症状の関連報告も束ねます。
  • 5. 既存の商品の更新の案内
    cc-safe-setup や各書籍で、その月にどんな更新が入ったかを整理します。読み返すべき章があれば案内します。

なぜ月額で届けるか（一回の本との違い）

一回の本（事故防止本、トークン本）は、公開した時点の事故と対処をまとめた、変わらない手引きです。深く一度に学ぶのに向いています。一方、Claude Code の費用や仕様や事故は毎月のように動きます。月刊の便りは、その月に新しく起きたことを実機で検証して追従し続ける役割です。位置づけが違うので、本の無償の更新と置き換わるものではありません。断片的な情報を自分で何時間もかけて集める代わりに、検証済みの月次の更新で最新に追えます。

一回の本との使い分け

  • 事故防止本（¥800・第3章まで無料） — データ消失と事故の防止の、変わらない手引き。一度きりの買い切りで、月ごとに新しい章を無償で追加。
  • トークン本（¥2,500） — トークンの費用を下げる、変わらない手引き。
  • CC Safety Lab（¥500/月） — 費用も仕様も含めた、その月の安全運用の便り。最新の事故にすぐ追従したい人へ。

無料の土台

cc-safe-setup（MIT・無料）が土台です。npx cc-safe-setup で基本の 8 つの安全 hook が入ります（破壊的な操作の遮断、main への push の防止、秘密情報の漏れの検知、編集ごとの構文の点検）。この月刊の便りは、無料の hook の運用を、毎月の鮮度で補う位置づけです。

A. 毎月 15 日ごろに発行します。月の途中で大きな事故が出たときは、号と号の間に速報を出すこともあります。
