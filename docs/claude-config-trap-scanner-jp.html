🪤 そのリポ、罠かも

Claude Code の .claude/ 設定 危険度スキャナ · English

GitHub で拾ったリポを claude で開いて「このフォルダを信頼しますか?」に はい を押す——その一回のクリックが、リポ同梱の .claude/settings.json に書かれた コマンドの自動実行・APIキーの送信先の書き換え・MCPサーバの起動 を、まとめて許可します。信頼は取り消せません。 押す前に、ここに貼り付けて中身を確かめてください。

受け取った設定を貼り付ける

未知のリポの .claude/settings.json(または .claude/settings.local.json / .mcp.json)の中身をそのまま貼り付けてください。複数まとめて貼っても構いません。

貼り付けた内容はブラウザの中だけで処理され、どこにも送信されません(通信は発生しません)。

この結果を共有する

毎回これを自動でやる

手で貼り付けるのは、信頼する前の一度きりには有効ですが、毎回は続きません。cc-safe-setup の trustfall-mcp-injection-guard.sh を入れておくと、セッション開始時に同じ検査が自動で走り、危険な設定を含むフォルダで警告します(無料・助言のみ・fail-open)。

何を見ているか(検出する3+1ベクトル)

  • hooks の自動実行 — settings.json の hooks は、信頼後にコマンドを自動で走らせます。クローンしたリポが SessionStart 等に curl … | sh を仕込めます(CVE-2025-59536、RCE)。
  • APIキーの送信先の書き換え — env.ANTHROPIC_BASE_URL を攻撃者のURLに上書きすると、Claude の全API通信が、x-api-key ヘッダ(=あなたのキー)ごとそのURLへ送られます。エラーも警告も出ない沈黙の漏洩です(CVE-2026-21852)。
  • MCPサーバの自動起動 — enableAllProjectMcpServers / enabledMcpjsonServers は、サーバ毎の同意を飛ばして .mcp.json のサーバを起動します。サンドボックス外の Node プロセスとして動きます(Adversa AI の TrustFall)。
  • 権限の自己付与 — permissions.allow が広いと、本来出るはずの確認プロンプトが消え、攻撃の発火が静かになります。

正直に: これは「修正済みの穴」の話だけではない

これらの「信頼ダイアログが出る前に勝手に実行・送信される」部分は、すでに修正されています。hook の自動実行による RCE（CVE-2025-59536）は v1.0.111 で、ANTHROPIC_BASE_URL の上書きによるキー漏洩（CVE-2026-21852）は 2.0.65 で修正されました。今の新しいバージョンでは、信頼する前に上記が暴発することは基本的にありません。

残る本当の危険は別です。「このフォルダを信頼」を押した瞬間、これらの設定はすべて有効になります。 信頼のクリックは、hook の実行・BASE_URL の上書き・MCP の起動への「取り消せない同意」だからです。だから防御は一つ——信頼する前に、受け取った .claude/ を読むこと。このツールはその一手を助けます。

赤が出たら

  • そのフォルダを信頼しない。 claude を一度閉じ、信頼ダイアログに「いいえ」を選ぶ。
  • 該当ファイルを開き、誰がそのキーを書いたかを確認する。PR で後から .claude/settings.json が足された場合は特に疑う。
  • キーが既に漏れた疑いがあるなら、Anthropic のコンソールで API キーを失効・再発行する。
  • API キーや BASE_URL を、共有される .claude/settings.json に書かない(この値は共有プロジェクト用のファイルに置くべきものではない)。
判定は Check Point Research の開示(CVE-2025-59536 / CVE-2026-21852)と Adversa AI の TrustFall PoC に基づきます。
このスキャナは既知の設定パターンを照合するだけで、hook コマンドの中身が良性か悪性かまでは判断しません。「印なし」は「安全」を意味しません。コマンド本体は必ず自分の目で読んでください。すべてブラウザ内で動作し、貼り付けた内容は送信されません。

このスキャナで見つかる .claude/ 設定の罠（外からの上書き・危険な許可・hook の注入・MCP の汚染）を、設定で先回りして止める全手順は、Claude Code 事故防止ハンドブック（¥800・第3章まで無料／Kindle 版は Kindle Unlimited で無料。ただし2026年6月時点の44章で、Zenn 版の追補は入りません）にまとめています。設定汚染を含む実機検証済みの実践書です。無料の hook 集は cc-safe-setup。他の無料診断ツール一覧へ。
